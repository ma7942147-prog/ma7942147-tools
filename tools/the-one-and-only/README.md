# the-one-and-only — 《The One and Only》MV

把使用者提供的 9 張插畫、4 段 15 秒短片、歌曲與 48 句歌詞，
合成 1920×1080 / 24fps / 4:32 的 MV。

## 檔案

| | |
|---|---|
| `build.py` | 素材正規化成 1920×1080 的片段（模糊底填滿 16:9、圖片加 Ken Burns 運鏡） |
| `lyrics_timed.json` | 48 句歌詞與時間點 |
| `subs.ass` | 燒錄用的字幕（WenQuanYi Zen Hei、白字黑邊、淡入淡出） |
| `the_one_and_only_48.srt` | 同樣時間的 SRT，可匯入剪輯軟體 |
| `tap.html` | 手機用的打點器（歌曲以 base64 內嵌） |
| `detect.py` | 從燒死字幕的影片裡還原歌詞與時間（字幕帶取樣＋切換點偵測） |
| `vocal_onsets.py` / `verify.py` | 用分離出的人聲軌驗證時間點 |

## 時間怎麼來的

第 1–45 句是使用者用 `tap.html` 邊聽邊按的實測值。
第 46–48 句（Outro）用分離出的人聲軌定位：3:53.75–3:55.75 是空白，
之後 3:56.0 / 4:01.0 / 4:05.25 各起一句，人聲在 4:08.25 收掉。

舊版 MV 的字幕只有 45 句、漏掉 Outro 那三句，
這也是先前分析時發現「最後 20 秒有人聲卻沒字幕」的原因。

## 畫面編排

18 個段落，跟著歌曲結構走。4 段短片放在主歌與間奏，
插畫做 Ken Burns 運鏡，重點畫面在副歌與尾奏再現。
段落之間 0.8 秒交叉溶接，開頭 1.6 秒淡入、結尾 4 秒淡出。

```bash
python3 build.py            # 產生 seg/*.mp4
# 之後用 xfade 串接 + subtitles 燒字幕 + 掛音軌（見對話紀錄的指令）
```
