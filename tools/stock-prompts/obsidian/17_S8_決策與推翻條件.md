# S8 ─ 形成決策，而且知道什麼時候改變看法

**回答的問題**：這套研究要怎麼變成可執行的決策？什麼情況下我要承認自己錯了？
**規則**：**不准只回答「買進／持有／賣出」**，要說明不同價格、不同情境下的風險報酬。

**這一步是整套系統的閉環**：產出的 `invalidation_triggers` 就是每日追蹤的檢查清單。

**跑的頻率**：每季（S7 之後）；論點改變時立刻更新。

## 🔁 閉環：這一步的產出去哪裡

`invalidation_triggers` → 抄進 `30_追蹤儀表板.md` 的觸發條件表 → 每天早上由 `20_每日盤前追蹤.md` 逐條檢查。

**如果 S8 沒有產出可檢查的觸發條件，那每天的追蹤就沒有意義。**
寫觸發條件的時候問自己：「如果我三個月後在放假，請別人幫我看，他看得懂嗎？」

## 📌 好的 vs 壞的觸發條件

| ❌ 壞 | ✅ 好 |
|---|---|
| 競爭變激烈 | 主要對手宣布新產能 ≥ 現有市場 20%，或報價下調 ≥ 10% |
| 成長趨緩 | 連續兩季營收 YoY 低於 15%，且指引再度下調 |
| 客戶流失 | 前三大客戶任一家占比較上年同期下降 ≥ 5 個百分點 |
| 估值太貴 | 股價進入 `risk_reward_by_price` 的「不參與」價格帶 |
