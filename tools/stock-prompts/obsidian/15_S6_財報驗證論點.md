# S6 ─ 用財報驗證投資論點

**回答的問題**：我原本的成長假設，被最新數據驗證了嗎？
**規則**：**不准只摘要財報。** 要逐條回去打勾原本的假設。財報摘要網路上到處都有，你要的是「我的論點還站得住嗎」。

**跑的頻率**：每季，個股財報後 48 小時內。
**下一步**：S6 完成後立刻跑 S7，再跑 S8。三個一組。

【必須完成】
1. 把原本的投資論點拆成一條一條可檢驗的假設（編號 A1、A2、A3…）。每一條要寫：
   - 這條假設對應到財報的哪一個數字或哪一段管理層說法
   - 原本預期是多少
   - 實際是多少
   - 判定：驗證 / 未驗證（數據不足）/ 反證

2. 針對以下項目逐項檢查並說明變化方向與幅度：

4. 最後將投資論點分成「變得更強 / 沒有明顯改變 / 變得更弱」，並說明是哪幾條假設造成這個結論。
5. 說明哪些數據最值得未來幾季持續追蹤（3–5 個），每個要寫「數字往哪個方向走代表論點被強化，往哪個方向走代表被削弱」。

## 📌 三個容易被忽略的訊號

1. **backlog 成長但營收沒成長** → 交貨瓶頸，通常是好事延後
2. **毛利率上升但來自產品組合而非漲價** → 一次性，下一季會回吐
3. **管理層開始換指標講話**（從 YoY 改講 QoQ，從營收改講調整後 EBITDA）→ 通常是原本的指標不好看了
