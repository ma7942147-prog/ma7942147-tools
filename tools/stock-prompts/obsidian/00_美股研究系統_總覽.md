# 🇺🇸 美股研究系統 — Jenny 八步驟（可程式化提示詞庫）

> 一句話：**由上而下，把「總體環境」一路推到「這檔股票什麼時候該改變看法」。**
> 每一步都有固定變數、固定輸出格式，所以可以排程、可以存檔、可以比較上一次跟這一次差在哪。

---

## 八步驟的邏輯鏈

| # | 步驟 | 回答的問題 | 產出餵給誰 |
|---|---|---|---|
| S1 | 總體環境 | 現在市場願意為哪一種特徵付溢價？ | S2、S5 的篩選權重 |
| S2 | 找市場主線 | 未來 3–5 年真正的結構性趨勢是什麼？ | S4 |
| S3 | 從新聞找線索 | 這則新聞改變了什麼？是趨勢還是雜訊？ | S2（升級成主線）或丟掉 |
| S4 | 拆產業鏈 | 錢會卡在價值鏈哪一節？ | S5 |
| S5 | 從產業篩公司 | 誰最會把產業成長變成獲利？ | S6 |
| S6 | 財報驗證論點 | 原本的假設被數據證實了嗎？ | S7 |
| S7 | 反推市場預期 | 現在股價已經假設了什麼？ | S8 |
| S8 | 形成決策 | 什麼情況下我要改變看法？ | 每日/每週追蹤的觸發條件 |

**關鍵**：S8 產出的「推翻條件（invalidation triggers）」就是每日追蹤要盯的東西。
沒有 S8，每日追蹤就只是看盤；有了 S8，每日追蹤才是在檢查論點。

## 📐 通用規則（每一個提示詞都已內建，不要刪）

```
【輸出紀律】
1. 先給人類可讀的分析，最後一定輸出一段 ```json 區塊，欄位名稱與範例完全一致，不得增刪。
2. 每個關鍵數字都要附「來源名稱＋發布日期＋連結」。查不到就填 null，並列進 unverifiable，不准推測。
3. 明確區分「事實」與「推論」：事實要有出處；推論寫成「若 X 則 Y」。
4. 使用最新可得資料。若資料截止日早於今天，明確寫出資料截止日。
5. 不給買賣建議、不給單一目標價。只給條件、機率、與不同價格下的風險報酬。
6. 每次輸出都要有 changed_vs_last 欄位：跟上一次相比，什麼變了、什麼沒變。
```

第 6 點是「可追蹤」的核心 —— 每次跑完都能回答「這週跟上週差在哪」。

## 🔗 跟你原本那套「決策卡」怎麼接

你在 `時間投顧_廖國峰先生_價值投資` 那套是 **灰度思考 → 估值 → 黑白決策 → 彩虹下注**，重點在「證據信度」與「部位大小」。
Jenny 這套的重點在 **找標的**。兩套是接得起來的：

| Jenny 八步驟 | 接到決策卡哪一格 |
|---|---|
| S3 / S6 的每一條發現 | 卡片1 灰度思考的 `E1/E2/E3` 證據列 |
| S7 的保守/基準/樂觀情境 | 卡片2 `intrinsic_conservative / base / optimistic` |
| S6 的 thesis_status | 卡片3 的決策依據 |
| S7 的 upside / downside | 卡片4 凱利公式的 `b` 與 `loss` |
| S8 的 invalidation_triggers | 卡片3 的「會推翻此決策的觸發條件」 |

**所以：Jenny 負責選出標的、算出 b 和 loss；廖國峰那套負責決定下多少。**
