# S3 ─ 從新聞找投資線索

**回答的問題**：這則新聞「改變了什麼」？是可以跑好幾年的產業趨勢，還是一次性事件？
**最重要的一欄**：`second_order` —— 市場通常會反映第一層（誰的股價要漲），漏掉第二層（誰的成本要變、誰的客戶要換供應商）。

**跑的頻率**：事件觸發。每日追蹤掃到重要新聞才升級跑完整版。
**下一步**：`is_structural: true` 且 `duration` ≥ 1–3 年 → 送進 S2 主線清單，再跑 S4。

## 📋 提示詞（複製這一段）

```text
你是一位產業分析師。今天是 {{DATE}}。

【新聞內容】
{{NEWS}}

【任務】
分析以上新聞，不要只摘要內容。

【必須完成】
1. 先說明「事件本身改變了什麼」：改變前是什麼狀態、改變後是什麼狀態。一句話講清楚差異。
2. 判斷它是否代表一個可以持續數年的產業趨勢。給出 短期事件／1 年內／1–3 年／3 年以上 的判定與理由。
3. 分析需求會傳導到哪些產業環節：畫出傳導鏈，每一節寫「哪些公司的營收或獲利可能因此改變」「影響的是營收還是毛利」「方向是正還是負」「大約落後幾季才會反映在財報上」。
4. 找出「目前市場可能還沒有充分反映的第二層影響」。至少 2 條。第二層的意思是：不是直接受惠者，而是受惠者的供應商、競爭者、替代品、或成本結構被改變的一方。
5. 判斷市場反映程度：充分／部分／尚未。並說明你從哪裡看出來（股價反應、分析師調整、成交量）。
6. 如果只是短期事件，直接指出原因，不要硬拗成趨勢。

3. 明確區分「事實」與「推論」：事實要有出處；推論寫成「若 X 則 Y」。

## 🗂️ 寫回哪裡

- `action: 忽略` → 只留在當日筆記，不用開新檔
- `action: 加入觀察清單` → 記到 `30_追蹤儀表板.md` 的觀察區
- `action: 升級為主線` → 加進 S2 主線清單，排下一次 S4

## 📌 常見誤判

| 看起來像趨勢，其實是 | 怎麼分辨 |
|---|---|
| 一次性大訂單 | 問「明年還會再下一次嗎」 |
| 補庫存 | 看終端需求有沒有同步成長 |
| 政策宣示但沒預算 | 找有沒有具體撥款金額與時程 |
| 同業都在講的話術 | 看有沒有反映在資本支出指引 |
