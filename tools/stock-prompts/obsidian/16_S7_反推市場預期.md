# S7 ─ 反推市場現在期待什麼

**回答的問題**：現在這個股價，已經假設未來會發生什麼事？
**規則**：**重點不是給目標價**，而是說清楚「股價要繼續漲，需要哪些事情發生」。
這一步是整套系統裡最反直覺、也最值錢的一步 —— 它把「這公司好不好」轉成「這個價格合不合理」。

**跑的頻率**：每季（S6 之後）；股價單月大幅變動時加跑。
**下一步**：S8。`upside` / `downside` 直接餵給決策卡的凱利公式。

## 🔗 接到你的決策卡

- `scenarios.保守.implied_price` → `intrinsic_conservative`
- `scenarios.基準.implied_price` → `intrinsic_base`
- `scenarios.樂觀.implied_price` → `intrinsic_optimistic`
- `upside_vs_price_pct` → 凱利公式的 `b`
- `downside_vs_price_pct` → 凱利公式的 `loss`
- 護欄照舊：**`b` ≤ 0 一律不下注**

## 📌 一個提醒

如果 `already_priced_in` 裡面每一條的 `actual_now` 都已經追上 `market_assumes`，代表這檔股票的「驚喜空間」用完了 —— 它可能還是好公司，但接下來只能賺到獲利成長的錢，賺不到評價擴張的錢。
