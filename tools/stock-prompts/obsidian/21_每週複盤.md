# 📆 每週複盤（30–45 分鐘）

**目的**：確認**環境**跟**主線**還是不是原本那個。個股的事交給每季的 S6/S7/S8。
**什麼時候跑**：週日晚上，或週一盤前。

---

## 📋 提示詞（複製這一段）

```text
你是我的投資研究助理。今天是 {{DATE}}，這是每週複盤。

【我的主線清單與追蹤清單】
{{WATCHLIST}}

【我上週的 S1 總體環境判定】
（貼上上週的 S1 JSON；沒有就寫「首次執行」）

【任務】四個部分。

一、S1 總體環境複核
重跑一次總體環境判定（成長、通膨、就業、利率、企業獲利），然後**明確回答：跟上週相比，市場環境判定改變了嗎？**
- 沒變：說明是哪些數據讓判定維持不變
- 變了：說明是哪一個數據造成翻轉，以及風格溢價（高成長／獲利品質／自由現金流／防禦性）跟著怎麼移動

二、主線健康度
針對每一條主線，用本週的公開資訊評分：
- 強化：出現新的訂單、資本支出、政策或財報證據 → 寫出證據
- 持平：沒有新資訊
- 減弱：出現反向證據 → 寫出證據
並判斷有沒有主線應該被降級（連續 4 週減弱）或被移除。

三、新主線候選
把本週累積的新聞線索匯總，判斷有沒有累積出「可以升級成主線」的題材。
升級門檻：需求來源明確 + 資金來源有公開數字 + 至少 2 家上市公司的營收會被實質影響。
沒有達標就明說沒有，不要為了交差硬湊。

四、下週行事曆與待辦
列出下週的重要經濟數據、財報日、以及我應該跑哪些步驟（S2/S4/S5/S6/S7/S8）。

【輸出紀律】
1. 先給人類可讀的四段摘要，最後輸出一段 ```json 區塊，欄位與下方一致。
2. 所有判定都要附來源與日期。查不到就填 null。
3. 不給買賣建議、不給目標價。
4. changed_vs_last 一定要填，這是這份週報最重要的一欄。

【JSON 格式】
```json
{
  "step": "WEEKLY",
  "week": "YYYY-Www",
  "date": "YYYY-MM-DD",
  "regime": "",
  "regime_changed": false,
  "regime_change_driver": "",
  "style_premium": {"高成長": "", "獲利品質": "", "自由現金流": "", "防禦性": ""},
  "style_premium_shift": "",
  "trend_health": [
    {"trend": "", "status": "強化|持平|減弱", "evidence": "", "weeks_weak_in_row": 0, "action": "維持|降級|移除"}
  ],
  "new_trend_candidates": [
    {"name": "", "meets_threshold": false, "missing": ""}
  ],
  "next_week_calendar": [{"date": "", "event": "", "why_it_matters": ""}],
  "tasks_next_week": [{"step": "", "target": "", "reason": ""}],
  "sources": [{"title": "", "publisher": "", "date": "", "url": ""}],
  "changed_vs_last": ""
}
```
```

## 🗂️ 每週紀錄怎麼存

用 `模板_每週複盤紀錄.md` 在 `每日筆記/` 建 `美股週報-YYYY-Www.md`。

## 📌 週報的價值在於「連續讀」

單看一週的週報沒什麼用。價值在於三個月後翻回去看：
- `regime` 欄位連續 12 週都一樣 → 你抓到了一個穩定環境，可以放大部位
- `regime` 每兩週就翻一次 → 通常不是市場在變，是**你的判定標準太敏感**，回去把 S1 的 `flip_threshold` 訂嚴一點
- 某條主線 `weeks_weak_in_row` 累積到 4 → 不用等它崩，先降級
