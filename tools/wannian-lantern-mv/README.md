# 萬年殿花燈夜 MV

2026-11-07 在台南市灣裡萬年殿拍攝的夜間花燈／公園造景（30 張）→ 帶字幕與運鏡的 MV。

## 重新產生
```bash
python3 build.py <照片資料夾> <輸出資料夾> [--layouts landscape,portrait] [--audio 自備音樂.mp3]
```
- landscape = 1920×1080（YouTube），portrait = 1080×1920（Shorts／Reels）
- 照片檔名需含 `captions.json` 的 id（拍攝時分秒）；字幕改 `captions.json` 即可
- 沒給 `--audio` 時用內建合成的五聲音階輕音樂（暫代；建議之後換成 Suno 歌曲，可接 `mv-creator`）
- 照片與成品影片不放進 repo（體積大、含個人拍攝內容）

## IG Reels 精剪版（reel.py）
```bash
python3 reel.py <照片資料夾> <輸出資料夾> [--audio 自備音樂.mp3]
```
- 1080×1920、約 55 秒；挑 18 張、淘汰 12 張（原因見 `reel_plan.json` 的 `rejected`）
- 調光（暖色、柔光、暗角）、緩推緩拉／橫移、90 BPM 卡拍點轉場、避開 IG 介面遮擋區
- 會裁掉手機燒錄在照片底部的機型／日期浮水印
- 文案與發佈提醒見 `ig_caption.md`

## 整體觀察
- 現場有「2026 萬年殿燈會」字樣（第 12 張圓盤），2026 為丙午馬年，所以馬（旋轉木馬、搖搖木馬、飛馬、「吉」字橘子）特別多。
- 另有蛇（戴財神帽）、虎、兔、狗、鼠等生肖造型，加上摩天輪（座艙是各種動物），像一整個生肖遊樂園。
- 穿山甲、貓頭鷹、長頸鹿、河馬等屬一般動物／童趣造型，不一定有生肖寓意。
- 蘿蔔（好彩頭）、爆竹（竹報平安）、福字、「吉」字橘子都是台灣常見的諧音祝福。
