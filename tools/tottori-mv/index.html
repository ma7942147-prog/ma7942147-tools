HOW TO RE-RENDER ／ 重新輸出

把歌曲放成 song.mp3，然後：
pip install numpy pillow imageio-ffmpeg
python3 analyze.py（產生音壓包絡，可略）
python3 scenes.py（重畫 17 張風景，輸出到 frames/）
python3 render.py tottori_mv.mp4（合成 MV）
歌詞時間改 timings.json 的 lines 即可，改完再跑 render.py。
