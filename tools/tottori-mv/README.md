# tottori-mv — 《金蓮》鳥取風景 MV

用 Python 程式「畫」出鳥取縣 17 處名勝（新海誠風的天空／逆光／雲隙光／鏡面水面），
再跟歌曲、歌詞合成成一支 1920×1080 的 MV。**沒有用到任何外部素材圖，17 張圖都是程式生成的。**

```
tools/tottori-mv/
├─ index.html      場景畫廊 + 歌詞時間軸（打開就能看）
├─ sync.html       🎧 歌詞對拍器：邊聽邊按空白鍵校正每句起始時間
├─ art.py          繪圖引擎（fbm 雜訊、雲、逆光、雲隙光、山稜、水面反射、砂丘風紋、後製）
├─ scenes.py       17 個場景的構圖
├─ render.py       Ken Burns 運鏡 + 交叉溶接 + 歌詞字幕 + 音壓脈動 → mp4
├─ timings.json    ★ 歌詞／場景的時間表（要改對拍就改這個檔）
├─ analyze.py      音壓包絡
├─ structure.py    段落邊界偵測（自相似矩陣 + checkerboard novelty）
├─ beats.py        BPM / 拍點 / 小節格
├─ phrases.py      人聲樂句偵測（中央聲道抽取後找換氣點）
├─ build_sync.py   把 timings.json 的歌詞灌進 sync.html
└─ scenes/         產生好的 17 張 2560×1440 風景圖
```

## 對拍怎麼做的

歌曲沒有時間碼，時間全是從音訊推的。第一版用「左右聲道相減抽中央聲道」的近似法，
結果抓到的是伴奏的起音點，歌詞整體早了 20 秒。現在改成真正的歌聲偵測：

`singing.py` — 四道關卡篩出「人在唱」的區間
1. **中央定位**：`mid - 1.15 × side`，把左右展開的合成器、殘響濾掉
2. **HPSS**：頻譜上時間方向取中位數 → 持續音（人聲、pad）；
   頻率方向取中位數 → 打擊音。用兩者的能量比當遮罩，把鼓濾掉
3. **人聲帶**：只留 250–3800 Hz（避開 kick 和 bass）
4. **音節速率**：人聲的音量會以 3–8 Hz 起伏（每秒 3–8 個字），
   把包絡帶通到這個頻段，變調越強分數越高

`lines_detect.py` — 用絕對門檻判斷「有沒有在唱」（這是擋掉前奏的關鍵），
在確定有人聲的區間內才做局部正規化切句。
`align.py` — 長樂句依內部低點（換氣）切開，再把 41 句歌詞依序排上去。

這首的結論：

| | 時間 |
|---|---|
| 第一聲人聲（0.67 秒的短吟，不是歌詞） | 0:23.70 |
| **歌詞開始** | **0:36.10** |
| 歌詞最後一句 | 4:33.22 |
| 人聲結束 | 4:35.34 |

0:23.7 那一聲的中央性是 2.50，跟已知人聲（0:36.1 是 2.48）一樣，
確定是人在唱；但只有 0.67 秒又接 11.7 秒空白，不可能是 11 個字的一整句，
所以判定為句前的吟唱，不放歌詞。

**兩道保險，確保歌詞不會跑在人聲前面：**
- 每一句的時間都是偵測到的歌聲起點（或歌聲區間內的換氣點），那個瞬間一定有人在唱
- 字幕的淡入從該時間點才「開始」（以前是提早 0.42 秒開始淡入），
  再加上 `timings.json` 的 `lyric_offset`（預設 0.25 秒）整體往後推

覺得還是早或晚，改 `lyric_offset` 一個數字就能整體平移，
或用 `OFFSET=0.4 python3 render.py out.mp4` 試不同值。

**要逐句對準就用 `sync.html`**：把 `song.mp3` 放同一層打開網頁，
播放，聽到每句開頭按空白鍵，匯出 JSON 貼回 `timings.json` 的 `lines`。

## 重新輸出

```bash
pip install numpy pillow imageio-ffmpeg
cd tools/tottori-mv
cp /path/to/你的歌.mp3 song.mp3
python3 analyze.py                # 音壓包絡（讓畫面跟著音量脈動，可略）
python3 scenes.py                 # 重畫 17 張圖 → frames/
SCENES=frames python3 render.py tottori_mv.mp4
```

只改歌詞時間的話，不用重畫圖：

```bash
python3 render.py tottori_mv.mp4          # 預設讀 scenes/ 這個資料夾
PREVIEW=53,62 python3 render.py test.mp4  # 只輸出 53–62 秒來試看
```
