# 紫璃工坊（Zili Atelier）

單頁 HTML 工具：用固定的角色模板（紫璃），組合場景／姿勢／服裝／氛圍／比例，
產生可直接貼到 AI 繪圖（Grok、Midjourney、SD 等）的英文提示詞。

## 用法
直接用瀏覽器打開 `index.html`（不需要伺服器、不需要 API key）。

1. 上方是鎖定的角色參考圖 —— 臉、髮色、髮箍固定不變
2. 依序點選：場景 → 姿勢 → 上身 → 下身 → 鞋子 → 氛圍 → 畫面比例
3. 需要時填「額外指示」（例：微風吹動髮絲、黃昏逆光）
4. 按 **複製提示詞**，貼到繪圖工具即可

## 功能
- 🎲 隨機搭配：一鍵換一整套
- ☆ 收藏搭配：喜歡的組合存起來，之後一鍵套用（存在瀏覽器 localStorage）
- ↺ 回到預設
- 選項會自動記住，下次打開還在

## 要加新選項？
編輯 `index.html` 裡的 `GROUPS` 陣列，每一項是 `["中文標籤", "english prompt fragment"]`。
角色外觀鎖定字串在 `CHARACTER_LOCK`，反向指示在 `NEGATIVE`。
