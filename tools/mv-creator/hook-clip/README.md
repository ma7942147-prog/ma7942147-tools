# hook-clip：MV → 直式短影音片段

把 16:9 的 MV 剪成 9:16（1080×1920）短影音，用在 Suno 短影音 hook 等平台。需要 `ffmpeg`。

## 怎麼挑片段
1. 先量每秒音量，找出前奏／主歌／副歌／結尾的位置。
2. 每 3 秒抽一張畫面拼成總覽圖，對照字幕確認每段唱的歌詞。
3. 起點選在「字幕剛換句＋音樂有空檔」的地方，盡量一刀到底，避免中間拼接。

## 紀錄：《停損》MV（2026-11-22）
原片：`停損_MV_字幕版.mp4`，2:28、1920×1080

| 版本 | 原片區段 | 長度 | 指令 |
|---|---|---|---|
| 完整 hook 版 | 0:36.8 → 2:27.0 | 110 秒 | `./make-hook.sh 停損_MV_字幕版.mp4 36.8 110.2 out.mp4` |
| 45 秒版 | 1:37.9 → 2:22.9 | 45 秒 | `./make-hook.sh 停損_MV_字幕版.mp4 97.9 45 out.mp4` |
| 45 秒純影片版 | 1:37.9 → 2:22.9 | 45 秒 | `./make-hook.sh 停損_MV_字幕版.mp4 97.9 45 out.mp4 silent` |

- 歌曲結構：0:00 前奏 → 0:24 主歌 → 0:37 導歌 → 0:47 副歌 → 1:15 第二段主歌 → 1:38 最後副歌 → 2:06 獨白「我輸給的是我自己」→ 2:15「明天……應該會漲吧」
- 交給 Suno 的是 **45 秒純影片版**（無聲、無字幕）。
- 原片字幕燒在畫面裡，`silent` 模式靠裁掉底部去字幕；有無字幕原檔時可改用原檔，不必裁。
- 影片檔太大，不放進 repo。
