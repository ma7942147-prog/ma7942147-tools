# taiwan-campus-mv — 〈大學時代〉台灣校園 MV

程式生成 18 張新海誠風的台灣大學校園風景，配上歌曲與對拍好的歌詞，
合成 1920×1080 的 MV。**沒有用任何外部素材圖，18 張都是 Python 畫的。**

## 對拍

**時間全部是實測值**，用 `tap.html` 邊聽邊按記下來的 37 個時間點，
第一句 0:17.12、最後一句 3:20.04。2:10.45–2:43.78 那 33 秒的空白就是
歌詞裡標的 `[Guitar Solo]`，剛好對上。

`tap.html` 把歌曲用 base64 內嵌在 HTML 裡（56kbps 單聲道），
手機打開就能播、就能打點，打完複製 JSON 貼回 `timings.json` 的 `lines`。
換歌只要重打一次點。

（自動偵測人聲起點的做法在前一個專案 tottori-mv 上失敗了三次，
 原因與程式留在 `tools/tottori-mv/separate.md`。這裡直接用實測值。）

## 重新輸出

```bash
pip install numpy pillow imageio-ffmpeg
cd tools/taiwan-campus-mv
cp /path/to/歌.mp3 song.mp3
python3 analyze.py            # 音壓包絡（畫面隨音量脈動，可略）
python3 scenes.py             # 重畫 18 張 → frames/
python3 render.py out.mp4     # 預設讀 scenes/
PREVIEW=15,23 python3 render.py test.mp4   # 只輸出 15-23 秒試看
```

`art.py` 是共用的繪圖引擎（fbm 雜訊、雲的受光邊、雲隙光、逆光暈、
空氣透視、水面鏡射、建築體、椰子樹、遠近並木、bloom / 色差 / 顆粒後製），
跟 `tools/tottori-mv/` 同一套，這裡多了 `trees(band=...)`（只畫樹林帶、
不會蓋住前景）和 `palm()`（會垂下葉子的椰子樹）。
