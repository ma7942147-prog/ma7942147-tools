# tooo-remix — 《The One and Only》Remix 版 MV

同一首歌的 house / slap-bass 混音版（2:51.6，比原版 4:32 短很多），
歌詞改寫成 40 句，素材是 5 段 15 秒短片與 4 張插畫。

| | |
|---|---|
| `tap.html` | 手機用的對拍器，歌曲以 base64 內嵌，聽到每句按一下 |
| `lyrics.json` | 40 句歌詞 |
| `sections.json` | 段落標記（主歌一／Build-Up／Drop／副歌／主歌二／橋段／Drop／尾奏） |
| `plan.json` | 14 段畫面的素材與時間邊界 |
| `build.py` | 把素材正規化成 1920x1080 24fps 的片段 |

## 素材處理

原始素材有 0.67（直式插畫）、1.78（橫式插畫與短片）、1.26、0.66 四種比例。
一律用「把自己放大裁切後模糊」當背景填滿 16:9，原圖等比縮放置中疊上去，
既不變形也不留黑邊。照片再加 Ken Burns（zoompan 逐格推近或拉遠並帶平移），
段落之間 0.8 秒交叉溶接。

## 流程

```bash
python3 build.py                     # seg/*.mp4（先算好，等時間點）
# 對拍完成後：產生 subs.ass → xfade 串接 + subtitles 燒字幕 + 掛音軌
```

時間點一律用 `tap.html` 的實測值。這個專案裡自動偵測人聲起點試過多次都不可靠
（原因與程式留在 `tools/tottori-mv/separate.md`），用耳朵打點是唯一準的做法。
