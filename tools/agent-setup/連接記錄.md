## 待接：Windows 本機 Claude Code

在你的 Windows 電腦上跑 `setup_windows.ps1` 完成。

| 服務 | 通道 | 鑰匙 | 為什麼要本機裝 | 狀態 |

## 本機環境需求

| 工具 | 為什麼需要 | 檢查指令 |
|------|-----------|----------|
| Node.js LTS | 本地 MCP server 幾乎都靠 `npx` 啟動，**沒裝 Node 是最常見的死因** | `node --version` |
| Git | repo 同步 | `git --version` |

## Windows 兩個經典坑（指南特別點名）

1. **`cmd /c` 包一層**：`claude mcp add <名稱> -- cmd /c npx -y <套件>`。
   不包會顯示「已安裝」但永遠連不上（`claude mcp list` 顯示 failed）。
2. **路徑反斜線**：設定檔裡寫 `C:/Users/...` 或 `C:\\Users\\...`，單一 `\` 會壞掉。

## 裝完必做

- **完全關掉 Claude Code 再重開**，MCP 才會生效。
- 重開後問一句：「你現在看得到哪些 MCP 工具？」

## 安全守則（本專案已落實）

- `.gitignore` 已擋 `.env`、`*.key`、`credentials.*`、`.claude/` — 金鑰不會進公開 repo。
- Firebase 走 `firebase login`（OAuth 登入式），**不要**下載服務帳戶 JSON 金鑰放進 repo。
- 個人／學生資料一律去識別化。
