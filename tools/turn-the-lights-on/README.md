# turn-the-lights-on — MV 合成

5 段影片 + 42 句歌詞 + 歌曲，合成 1920×1080 / 24fps / 3:49.75 的 MV。

## 實測的段落起點

用 `tap.html` 邊聽邊打點取得，非推估。

| 主歌一 | 0:42.22 |
| 導歌一 | 1:04.43 |
| 副歌一 | 1:25.69 |
| 主歌二 | 2:01.97 |
| 導歌二 | 2:21.32 |
| 副歌二 | 2:33.64 |
| 尾奏 | 3:03.75 |

## 畫面依歌詞意義安排

素材：clip1 復古食堂卡座、clip2 兩人趴桌笑鬧、clip3 庭院長椅的一家人
（畫面帶 '84 12 18 日期戳）、clip4／clip5 房間裡的女子（直幅 800×1136）。

19 個切點全部踩在段落上，配片邏輯：

- 前奏的氣音低語 → clip5 獨處的房間
- 「遠遠向我招手」→ clip4 轉身揮手的動作
- 「中山北路的海霸王」→ clip1 復古食堂
- 「兩個女兒都長大成家」→ clip3 一家人的長椅
- 「長髮被風吹散」→ clip5
- 「三十年，四個人的空房間」→ clip5 空鏡收尾

素材共 65 秒、歌長 230 秒，所以每段重複使用 3–4 次。
`build.py` 每次取不同的時間區段（`start=k*1.6`），
長度不夠的區間用 `setpts` 降速填滿（最慢 0.51×，落在最後的淡出段）。
縱橫比不一的素材一律用「放大裁切後模糊的自己」墊底填滿 16:9。

## 字幕

`subs.ass` 有兩種樣式：`Lyric` 給一般段落，`Soft` 給開頭的氣音低語與尾奏，
字級小一點、字距鬆一點。`turn_the_lights_on.srt` 是同樣時間的 SRT。

```bash
python3 build.py        # seg/*.mp4 を作る
# xfade で連結 → subtitles で焼き込み → 音声を multiplex
```
